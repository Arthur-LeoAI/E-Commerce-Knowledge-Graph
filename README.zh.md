# 电商运营全景图谱（E-commerce Operations Atlas）

[English](README.md) · **中文**

一个免费、开源、面向新手的电商全景图。目标是让没有经验的人看懂电商这门生意，并且实事求是地规划第一个产品。

- **知识图谱**：9 个业务领域（战略、产品、合规、物流、店铺、营销、销售、财务、数据与组织），48 个节点，106 条因果关系。每个节点都有通俗的解释和一个算好的例子。
- **带来源的市场规则**：在 Amazon 美国站销售涉及的 24 条规则，分为**法律**（美国联邦和州）和**平台规则**（Amazon 美国站）。每条规则都列出来源、核对日期和下次复查日期。
- **透明的计算器**：落地成本、平台费用、单件利润、盈亏平衡广告费、月利润、补货点、首批备货资金和时间线。每个结果都列出计算过程。
- **AI 技能**：让 AI 助手讲解同一套内容、列出适用规则，并用你的数字跑计算器。
- **中英双语**：所有内容都有英文和中文。

> 本项目用于学习，**不构成法律、税务或财务建议**。规则会变化，行动前请查看来源并咨询专业人士。详见 [DISCLAIMER.md](DISCLAIMER.md)。

## 网站

网站由数据文件自动生成，通过 GitHub Pages 发布，共七个页面：

| 页面 | 内容 |
|---|---|
| 新手导览 | 跟着一个虚构产品（折叠硅胶水杯）走完 8 个环节，最后用一张图看清单件利润 |
| 全景图谱 | 逐层展开：业务主流程 → 一个领域 → 一个节点。另有 3D 视图，以及一次显示全部 48 个节点的分组视图，可查看最多 3 层的连锁影响 |
| 从零开始 | 按顺序排列的八个阶段，每个阶段写明要产出什么、最常见的错误和相关节点 |
| 计算器 | 每个输入框默认填示例数字并标明"示例"，换成你自己的数字后，每个结果都会列出计算过程 |
| 市场规则 | 选择你在哪里销售，查看适用的法律和平台规则，附来源和复查日期 |
| 数据化路线 | 图谱以后怎样接入真实数据，哪些分析可以算准、哪些需要验证 |
| 来源 | 规则引用的全部来源 |

在本地运行：

```bash
npm ci
npm run serve        # 生成 dist/ 并在 http://localhost:8080 预览
```

## 刻意不做的事

- **不做选品排行或"最值得卖的产品"清单。** 抓取亚马逊数据违反其条款；亚马逊的数据接口不能自由转发，第三方数据也有各自的付费条款；而且公开的排行本身就会让它显示的机会消失。图谱只讲选品的*方法*。
- **不编造数字。** 示例数字一律标明是示例。"健康区间"只有在有来源支撑时才会显示，所以 `benchmarks/` 目前是空的。
- **不涉及个人数据。** 这里不收集、不存储任何客户信息。网站不向任何第三方发请求，没有外部字体、脚本或追踪器。

## 仓库结构

```
data/          知识图谱：领域、nodes/（每个节点一个文件）、关系、术语、导览、阶段、页面文字、界面文字、示例
rules/         law/us/（含 law/us/ca/）、platform/amazon/us/，每条规则一个 YAML 文件
benchmarks/    有来源的"常见参考区间"（有来源之前保持为空）
models/        calculators.js（纯函数，无依赖）和测试
schemas/       每类数据的 JSON Schema
site/          index.html 和 app.js，由 scripts/build-site.mjs 生成到 dist/
skill/         SKILL.md、atlas.mjs（JSON 查询工具）和测试
scripts/       校验、构建、预览、规则过期检查
legacy/        最初的单文件原型（保留作参考）
```

## 开发

```bash
npm ci
npm run validate     # 检查格式、引用关系、中英文是否齐全
npm test             # 计算器和技能的测试
npm run build        # 生成 dist/
npm run stale        # 列出已过复查日期的规则
```

每次推送和 Pull Request 都会自动运行校验、测试和构建。每天有一个定时任务，发现规则过了复查日期就自动开 Issue。推送到 `main` 会自动部署网站。

### 数据规则摘要

- 每段面向用户的文字都必须同时有 `en` 和 `zh`，缺一种语言校验就会失败。
- 规则分两类：
  - `kind: law`：政府制定，在任何平台销售都适用；
  - `kind: platform`：平台制定，只适用于一个站点。

  每条规则都必须有 `sources`、`last_checked` 和 `next_review`。
- 计算器把每一项金额四舍五入到分，合计时把四舍五入后的分项相加。时间永远是区间（最短 / 一般 / 最长）。

## 使用 AI 技能

见 [skill/SKILL.md](skill/SKILL.md)。运行 `npm ci` 之后，可以直接调用查询工具：

```bash
node skill/atlas.mjs rules --topic fees
node skill/atlas.mjs calc price=24.99 fulfilment_fee=4.6
```
